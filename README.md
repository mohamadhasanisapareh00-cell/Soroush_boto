# 🤖 ربات سروش

ربات ارسال خودکار پیام در گپ‌های سروش پلاس.

## ✨ امکانات

- 📤 ارسال خودکار پیام در گپ‌ها با فاصله زمانی
- 👥 مدیریت لیست گپ‌ها
- 💬 مدیریت پیام‌ها
- 🔗 ورود به گپ با لینک دعوت
- 📊 آمار و وضعیت لحظه‌ای
- 👑 سیستم مالکیت

## 🛠️ نصب

git clone https://github.com/mohamadhasanisaparch00-cell/ربات-سروش.git
cd ربات-سروش
pip install -r requirements.txt

## 🚀 اجرا

export PHONE="+98xxxxxxxxxx"
python main.py
